# FireChat

O FireChat é um aplicativo de bate-papo em tempo real para Android, desenvolvido com Kotlin e Jetpack Compose.

## Construído com

* [Kotlin](https://kotlinlang.org/) - Linguagem de programação de primeira classe e oficial para desenvolvimento Android.
* [Jetpack Compose](https://developer.android.com/jetpack/compose) - Kit de ferramentas moderno para construir interfaces de usuário nativas para Android.
* [Firebase](https://firebase.google.com/) - Plataforma móvel para desenvolvimento de aplicativos, com recursos como autenticação, banco de dados em tempo real e armazenamento.
* [Hilt](https://dagger.dev/hilt/) - Biblioteca de injeção de dependência para Android.

## Começando

Para obter uma cópia local em funcionamento, siga estes simples passos de exemplo.

### Pré-requisitos

* Android Studio Iguana | 2023.2.1 ou posterior
* Gradle 8.0 ou posterior

### Instalação

1. Clone o repositório
   ```sh
   git clone https://github.com/seu_usuario/FireChat.git
   ```
2. Abra o projeto no Android Studio
3. Adicione o seu arquivo `google-services.json` ao diretório `app`.
4. Construa e execute o aplicativo.
